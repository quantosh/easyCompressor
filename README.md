Extensión de navegador que aplica compresión dinámica de audio en cualquier pestaña. Incluye medidor VU en tiempo real, ecualizador de 3 bandas y modos simple (intensidad) y avanzado (parámetros completos).

## Descargar

Descarga el ZIP correcto para tu navegador desde [Releases](https://github.com/quantosh/easyCompressor/releases):

- `Easy.Compressor-chrome.zip` para Chrome
- `Easy.Compressor-edge.zip` para Edge
- `Easy.Compressor-firefox.zip` para Firefox

## Instalación manual

**Chrome / Edge:**
1. `chrome://extensions` → Modo desarrollador
2. Cargar extensión sin empaquetar → seleccionar carpeta

**Firefox:**
1. `about:addons` → Engranaje → Instalar complemento desde archivo
2. Seleccionar el ZIP

## Uso

1. Abre el popup desde la barra del navegador
2. Activa el compresor con el botón Enable
3. Ajusta intensidad (modo simple) o parámetros (modo avanzado)
4. El VU meter muestra el nivel y la reducción de ganancia en tiempo real
